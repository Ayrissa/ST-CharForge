# CharForge — конструктор персонажей для SillyTavern

Расширение помогает быстро создать **компактное досье персонажа** (по умолчанию до ~1000 токенов): ты описываешь идею своими словами, а ИИ структурирует и достраивает её по продуманной анкете.

*English: CharForge builds dense, token-efficient character dossiers (≈1000 tokens) from a short concept. The UI is Russian by default with an English option; the dossier itself is always generated in English.*

## Возможности

- Открывается через **меню волшебной палочки** или командой `/charforge`.
- **Универсальная анкета**: базовые данные, внешность, характер (внешний и внутренний), прошлое, навыки, детали образа, сексуальность, взаимоотношения, манера речи с примерами реплик. Любую секцию (кроме базовых данных) можно отключить в настройках.
- **Экономия токенов**: плотный формат «ключ: значение», фрагменты вместо предложений, лимит слов на каждую секцию. Счётчик токенов показывает, влезла ли анкета в бюджет, а кнопка **«Сжать»** ужимает её одним запросом.
- **Референсы**: текстовые заметки и картинки (для мультимодальных моделей; сжимаются до 768 px).
- **Перегенерация отдельных секций** с необязательным пожеланием.
- **Ручное редактирование** любой секции.
- **Результат**: создать персонажа прямо в Таверне (всё в поле Description), скопировать текст или экспортировать карточку JSON (Character Card V2).
- **Профили подключения**: запросы идут через Connection Manager. Ключи API остаются внутри Таверны, расширение их не видит и не читает.
- **Настройки**: язык интерфейса, профиль, бюджет, лимит ответа, число примеров реплик, секции, цвета.
- Адаптивный интерфейс для десктопа и телефона.
- Черновик (описание, референсы, анкета) сохраняется между сессиями.

## Установка

В SillyTavern: **Extensions → Install extension** и вставь ссылку:

```
https://github.com/Ayrissa/ST-CharForge
```

Для работы нужен включённый встроенный **Connection Manager** и хотя бы один профиль подключения.

## Использование

1. Открой **Extensions → CharForge** и выбери профиль подключения (или оставь текущий).
2. Открой окно: волшебная палочка → **Конструктор персонажей**.
3. Опиши персонажа, добавь референсы и нажми **«Сгенерировать анкету»**.
4. Поправь секции вручную или перегенерируй нужные.
5. Если анкета превышает бюджет, нажми **«Сжать»**.
6. Нажми **«Создать персонажа»**.
