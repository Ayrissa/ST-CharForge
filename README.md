# CharForge — конструктор персонажей для SillyTavern

Расширение помогает быстро создать **компактное досье персонажа** (по умолчанию до ~1000 токенов): ты описываешь идею своими словами, а ИИ структурирует и достраивает её по продуманной анкете. Также умеет писать первое сообщение и хранит персонажей в собственной библиотеке.

## Возможности

- Открывается через **меню волшебной палочки**, из панели Extensions или командой `/charforge`.
- **Три вкладки**: Создание, Библиотека, Настройки.
- **Универсальная анкета**: базовые данные, внешность, характер (внешний и внутренний), прошлое, навыки, детали образа, сексуальность, взаимоотношения, манера речи с примерами реплик. Любую секцию (кроме базовых данных) можно отключить.
- **Имя** задаётся отдельным полем (или придумывается ИИ). **Аватар** карточки загружается отдельно.
- **Свобода додумывания**: Строго / Баланс / Смело. Отдельный переключатель «додумывать окружение» создаёт именованных родных, друзей и врагов.
- **Первое сообщение** со своим лимитом слов (до 400), необязательной сценой, выбором языка и оформления (*действия* и «реплики», обычный текст или «речь» + обычный текст в литературном стиле). Не входит в токены анкеты.
- **Экономия токенов**: плотный формат «ключ: значение», лимит слов на секцию, счётчик токенов и кнопка «Сжать».
- **Референсы**: текст и картинки (для мультимодальных моделей).
- **Перегенерация и ручная правка** любой секции. Если модель пропустила или оборвала секцию, расширение само дописывает её отдельным запросом; пустые секции можно сгенерировать вручную.
- **Библиотека персонажей**: сохранение, поиск, открытие в редакторе, создание в Таверне, экспорт JSON, удаление.
- **Темы**: Авто (цвета текущей темы Таверны), Полночь, Роза, Лес, Бумага.
- **Результат**: создать персонажа в Таверне (анкета в Description, первое сообщение в First Message, аватар), скопировать текст или экспортировать карточку JSON (Character Card V2).
- Адаптивный интерфейс для десктопа и телефона. Черновик сохраняется между сессиями.

## Установка

В SillyTavern: **Extensions → Install extension** и вставь ссылку:

```
https://github.com/Ayrissa/ST-CharForge
```

## Использование

1. Открой конструктор и на вкладке **Настройки** выбери профиль подключения (или оставь текущий).
2. На вкладке **Создание** опиши персонажа, добавь референсы и аватар, нажми **«Сгенерировать анкету»**.
3. Поправь секции вручную или перегенерируй нужные. Если анкета превышает бюджет, нажми **«Сжать»**.
4. Сгенерируй **первое сообщение** (по желанию укажи сцену).
5. Нажми **«Создать персонажа»** или **«В библиотеку»**.
